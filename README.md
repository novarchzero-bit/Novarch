# 🏗️ NOVARCH - Les nouveaux architectes de la vie

**NOVARCH** est un site web moderne présentant une agence de coaching et de transformation numérique basée à Bamako, Mali.

---

## 📋 Description

NOVARCH accompagne les personnes et les organisations à construire leur avenir grâce à la vision, l'innovation et la transformation. Le site met en avant les services dans quatre domaines clés :

- 🚀 **Transformation** - Développez votre potentiel et votre mentalité
- 🎯 **Stratégie** - Construisez une direction claire pour réussir
- 💡 **Innovation** - Créez les solutions du futur
- 📈 **Développement** - Améliorez vos compétences

---

## 🚀 Démarrage rapide

### Prérequis
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- (Optionnel) Python ou Node.js pour servir le site localement

### Installation

1. **Clonez le repository** :
```bash
git clone https://github.com/novarchzero-bit/Novarch.git
cd Novarch
```

2. **Lancez le site** :

#### Option 1 : Ouverture directe (la plus simple)
Double-cliquez sur le fichier `index.html` ou ouvrez-le dans votre navigateur.

#### Option 2 : Avec un serveur local Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
Puis ouvrez `http://localhost:8000` dans votre navigateur.

#### Option 3 : Avec Node.js
```bash
npx http-server
```
Ouvrez l'adresse affichée (généralement `http://localhost:8080`).

#### Option 4 : Avec GitHub Pages
1. Allez dans **Settings** (Paramètres) du repository
2. Naviguez vers **Pages**
3. Sélectionnez la branche `main` comme source
4. Le site sera accessible à : `https://novarchzero-bit.github.io/Novarch/`
